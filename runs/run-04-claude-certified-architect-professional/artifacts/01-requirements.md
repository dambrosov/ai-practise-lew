# Requirements: Claude Certified Architect – Professional

## Summary
The learner wants to pass the "Claude Certified Architect – Professional" certification exam within 3 months (13 weeks, 2026-10-02 to about 2027-01-01). The learner is an experienced engineer (16 years) with about 6 months of hands-on Claude Code use. The budget is 14 h/week for 13 weeks, a total of 182 h, using free resources only. Checkpoint quizzes and mock assessments are wanted. Six success criteria are defined.

## Content

### Learner goal and target outcome
**Goal:** By the end of week 13 (about 2027-01-01) the learner can pass the "Claude Certified Architect – Professional" exam. The learner can design, justify and critique Claude-based solution architectures (including Claude Code workflows, agents, tools/MCP and plugins) at the level the exam objectives require, and can score at or above the pass level on a full-length practice assessment.

**Context:** The learner wants the credential as formal validation of existing practical Claude Code experience, and to extend that experience into architect-level knowledge.

| Area | Level | Evidence from the input |
|---|---|---|
| Software engineering in general | strong | 16 years of software engineering |

| Claude Code extensibility (marketplace plugins) | working | has created marketplace plugins |
| Claude API / model-level concepts (prompting, tool use, context management, evaluation) | basic (assumed) | not stated; conservative assumption, to be verified by the knowledge assessment |
| Agent / multi-agent architecture and MCP | basic (assumed) | not stated beyond plugin creation; to be verified |
| Exam content and format of the certification | none | not stated; the learner has not taken the exam |

### Preferences
- Learning style: reading, quizzes and hands-on practical tasks.
- Formats: documentation and articles, checkpoint quizzes, practical tasks, practice/mock exams. Hands-on work should build on Claude Code.
- Pace: steady daily sessions of 2 h; a lighter day per week may serve as buffer.
- Avoid: paid resources, content that repeats basic software engineering, resources that need paid API usage.

### Scope
In scope:
- All topics covered by the official exam objectives of the "Claude Certified Architect – Professional" certification.
- Gap-driven study of Claude architecture topics the learner does not yet know well.
- Practical tasks that apply the topics, with a capstone.
- Checkpoint quizzes and at least one full-length mock assessment.
- Final exam-review period at the end of the schedule.

Out of scope:
- General software engineering, cloud or programming fundamentals.
- Paid courses, paid practice exams and paid tools.
- Other vendor certifications and other Claude certification levels.
- Registering for or paying for the exam, and exam-day logistics beyond a readiness checklist.
- Production deployment of the practical tasks.

### Success criteria
1. The learning path covers 100% of the published exam objectives or domains, with each mapped to at least one module and resource.
2. The weekly schedule totals no more than 182 h and no more than 14 h in any week, and ends with a review week before the target exam date.
3. Every resource is free to use, and its URL was verified as reachable.
4. The path includes at least one checkpoint quiz per major module and at least one full-length mock assessment, taken before the last week.
5. The path includes practical tasks and a capstone that exercise the architect-level skills in Claude Code.
6. The learner scores at least 80% on the final mock assessment (assumed readiness threshold; the actual pass mark is to be confirmed from official sources).
